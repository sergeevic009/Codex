ВСЕ ИСХОДНИКИ RIME

АКТУАЛЬНЫЕ ВЕРСИИ
index.html — выбор между приложениями и концепция третьей версии.
rime-paint-kids.html — Rime Friends, рисование для детей 3–10 лет.
rime-paint-adult.html — Rime Studio, рисование и аналитика с 11 лет.
rime-paint.html — копия Studio для совместимости со старым именем.

Rime Pulse — пока предложенное название и концепция на стартовой странице.
Отдельный редактор видео, чаты и общая социальная сеть ещё не реализованы.

ЗАПУСК
Распакуй весь архив. Открой index.html в Chrome, Edge или Firefox.
Для локального веб-сервера: python start.py (требуется Python 3).
Оставь окно сервера открытым, пока используешь сайт.
HTML содержит разметку, CSS и JavaScript: это весь код приложения.
Сборка и установка npm-пакетов не нужны.

ДОПОЛНИТЕЛЬНЫЕ ФАЙЛЫ
assets/ — исходные PNG-иллюстрации Аки и шести чиби.
Они уже встроены в HTML Friends, поэтому приложение работает без этой папки.
history/ — сохранённые предыдущие версии. Для работы используй актуальные файлы в корне.
original-upload/ — исходный HTML, с которого началась работа.
.nojekyll — настройка для публикации на GitHub Pages.

ЧТО ВАЖНО ЗНАТЬ
Вход в Friends демонстрационный: SMS и письма не отправляются,
владение номером/почтой не подтверждается. Серверная авторизация не подключена.
Рисунки, профиль, музыка и обои сохраняются в текущем браузере на устройстве.
При другом адресе сайта, браузере или очистке данных они могут стать недоступны.
Для важных работ используй кнопку «Сохранить».
ИИ-анимация и платные разговоры с чиби не подключены.
Поиск фотографий и автоматическая загрузка внешних фото удалены из Friends.
API-ключей и секретов в этом архиве нет.
